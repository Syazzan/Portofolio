# SYAZZ — Personal Portfolio

SYAZZ adalah website personal portfolio yang dibuat sebagai media untuk memperkenalkan diri, menampilkan kemampuan, perjalanan belajar, serta berbagai project dan kreativitas di bidang teknologi.

Website ini merepresentasikan perjalanan gw sebagai pelajar SMK yang memiliki passion di bidang **Frontend Development, Creative Web Design, dan Basketball**. Dibangun dengan konsep *Dark Cinematic & Modern Editorial*, menggunakan perpaduan warna hitam, merah, tipografi bold, serta berbagai elemen visual yang interaktif.

Di dalamnya terdapat beberapa section, mulai dari About Me, My Journey, Technical Skills, Services, Projects Showcase, hingga Creative Playground yang menghadirkan berbagai eksperimen interaktif menggunakan JavaScript. Ada juga section khusus Basketball sebagai representasi passion gw di luar dunia coding.

Website ini dikembangkan menggunakan HTML, CSS, dan JavaScript dengan berbagai fitur seperti smooth scrolling, scroll animations, interactive navigation, project filtering, project modal, animated elements, dan responsive layout.

Bukan sekadar tempat untuk memamerkan hasil karya, website ini juga menjadi bagian dari proses gw untuk terus belajar, mengeksplorasi hal baru, meningkatkan kemampuan, dan membangun langkah menuju cita-cita menjadi seorang **Software Engineer**.
